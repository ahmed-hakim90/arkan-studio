### Manifesto
**AR title:** نحن لا نبني ما يراه المستخدم فقط.
**EN title:** We don’t only build what the user sees.

Body (AR): كل شاشة جيدة تقف خلفها منظومة لا يراها المستخدم. قواعد عمل. صلاحيات. بيانات. عمليات. تكاملات. أتمتة. قرارات. لهذا لا نتعامل مع المشروع كمجموعة صفحات. نتعامل معه كنظام. نرسم كيف يبدأ العمل. كيف تنتقل البيانات. من يتخذ القرار. ما الذي يمكن أتمتته. وما الذي يجب أن يحدث عندما يكبر المشروع. ثم نبني الواجهة فوق أساس يستطيع تشغيله.

Body (EN): Behind every good screen sits a system the user never sees. Business rules. Permissions. Data. Processes. Integrations. Automation. Decisions. So we don’t treat a project as a set of pages. We treat it as a system. We map how work starts, how data moves, who decides, what can be automated, and what must happen when the project grows. Then we build the interface on a foundation that can run it.

Footer: الواجهة هي الجزء الذي تراه. النظام هو ما يجعلها تعمل. / The interface is what you see. The system is what makes it work.

Layers: Interface · Workflow · Application · Data · Automation · Integrations · Infrastructure

### What we build (not “Services”)
1. **Business Systems** — أنظمة للأعمال · ERP · Internal Tools · Finance · CRM · Inventory · Approvals · Reporting
2. **Operations Systems** — Field Operations · Dispatch · Locations · Assets · Tickets · Tracking · Workforce
3. **Platforms & SaaS** — SaaS · Marketplaces · Portals · Multi-role · Subscriptions · Admin
4. **Commerce** — Ordering · Payments · Inventory · Merchants · Delivery · Fulfilment
5. **AI & Automation** — Document Intelligence · Vision · Assistants · Extraction · Workflow Automation · Decision Support · Closing: AI ليس المنتج. أحيانًا هو الجزء الذي يجعل المنتج أذكى. / AI is not the product. Sometimes it’s the part that makes the product smarter.
6. **Digital Experiences** — Corporate · Product Websites · Interactive Experiences · Portals · Design Systems
